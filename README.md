# 냉털이

![냉털이 프로젝트 배지](https://img.shields.io/badge/냉털이-자취생%20냉장고%20요리사-F36B3F?style=for-the-badge)

냉장고에 남은 재료로 만들 수 있는 요리와 식재료 보관법을 추천하는 자취생을 위한 웹 챗봇입니다.

## 프로젝트 소개

### 만들고 싶은 이유

자취를 하면 냉장고에 식재료가 남아 있어도 무엇을 만들어야 할지 떠오르지 않아 배달 음식을 주문하거나 재료를 버리게 되는 경우가 있습니다. 냉털이는 집에 있는 재료를 쉽게 활용하여 식비와 음식물 쓰레기를 줄일 수 있도록 돕기 위해 시작한 프로젝트입니다.

### 예상 사용자

- 냉장고의 남은 재료를 알뜰하게 활용하고 싶은 자취생
- 요리 경험이 많지 않아 간단한 레시피가 필요한 사람
- 짧은 시간 안에 한 끼를 해결하고 싶은 학생과 직장인
- 식재료를 오래 보관하는 방법이 궁금한 사람

## 구현해 보고 싶은 기능

- [x] 입력한 식재료를 기반으로 요리 레시피 추천
- [x] 요리의 예상 소요 시간, 기본 양념, 조리 순서 안내
- [x] 대파, 양파, 감자, 계란, 두부 등의 식재료 보관법 안내
- [x] 추천 질문 버튼과 대화 내역 초기화 기능
- [x] 브라우저 `localStorage`를 활용한 대화 내용 저장
- [x] PC와 모바일을 지원하는 반응형 화면
- [ ] 사용자가 보유한 재료에 따른 다양한 레시피 추가
- [ ] 알레르기 정보와 선호하는 음식을 반영한 추천
- [ ] 외부 API를 활용한 더 자연스러운 챗봇 대화

## 현재 진행 상태

기본 챗봇 화면과 핵심 기능을 구현했습니다. 현재는 미리 작성한 레시피와 보관 정보 데이터를 기반으로 답변하며, 앞으로 추천할 수 있는 요리와 식재료 정보를 계속 추가할 계획입니다.

## 실행 방법

프로젝트 폴더에서 `index.html`을 브라우저로 열거나, 다음 명령으로 로컬 웹 서버를 실행합니다.

```bash
python3 -m http.server 8000
```

서버를 실행한 후 브라우저에서 [http://localhost:8000](http://localhost:8000)으로 접속합니다.
